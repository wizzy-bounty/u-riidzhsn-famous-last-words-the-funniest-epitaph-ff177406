A program/v1 entry for the make.fun competition "Famous Last Words: The Funniest Epitaph".

`main.py` writes a single one-line tombstone epitaph (at most 150 UTF-8 characters, no trailing newline) to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (falling back to `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
